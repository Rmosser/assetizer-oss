# 选片篮（Chrome 扩展）

在 YouTube 上把视频攒进选片篮，再整批交给课代表的新专题。机制与理由见 [docs/topics.md](../docs/topics.md)「选片扩展」。

## 装

1. Chrome 打开 `chrome://extensions`，右上角打开「开发者模式」。
2. 「加载已解压的扩展程序」，选这个 `extension/` 文件夹。
3. 把工具栏的拼图菜单里的「课代表 · 选片篮」固定出来（角标写着篮子里有几期）。
4. 默认交给 prodbox；要换成 devbox 或本机，在扩展的「详细信息」→「扩展程序选项」里选。

改了代码在 `chrome://extensions` 里点这个扩展的刷新；已经开着的 YouTube 页面要刷新一下才会重新挂上勾。

## 用

- 鼠标移到缩略图上，点左上角的圆勾；或者指着缩略图按 `x`。观看页按 `x`，或点标题右端的圆勾。
- 任何网页上的 YouTube 链接：右键「加入选片篮」。
- 点工具栏图标打开侧边栏：看篮子、移出、清空；当前是播放列表时可以「+ 这个列表」。
- 「交给课代表」：课代表的专题页打开，新专题里这批已经列好、勾好；写下问题再「开始」，或切到「已有专题」加进去。进了专题的从篮子里移出，其余留着。页面领走了侧边栏才写「已送出」；15 秒内没有页面领走（盒子没开、没登录）写「没交出去：连不上课代表」，篮子不动，再交还是这一批。

## 文件

| 文件 | 做什么 |
|---|---|
| `src/sites/youtube.js` | YouTube 适配器：认卡片、读标题频道时长、观看页的当前视频、播放列表。YouTube 改版时改这里 |
| `src/content.js` | YouTube 页面上的勾、`x`、观看页的圆勾、自检 |
| `src/basket.js` | 篮子（`chrome.storage.local`）与交接的批次 |
| `src/background.js` | 角标、右键菜单、找开着的课代表标签页或新开一个 |
| `src/bridge.js` | 课代表页面上的内容脚本：把这一批交给页面，收到「交好了」后移出 |
| `panel.*` | 侧边栏 |
| `options.*` | 选交给哪台盒子 |

检查：`cd web && npm run test:extension`（见 [docs/quality.md](../docs/quality.md)）。
