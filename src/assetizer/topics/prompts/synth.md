# 综合：把一批视频的笔记合成对一个问题的回答

用户一次看了一批视频，想弄清一个问题：{question}
{notes}

下面是每期视频的笔记，按 V1、V2……编号。每期的笔记都是另一个写作代理照着底稿和回看写的，事实后面标了来源：`[12:34 说]`（讲者原话）、`[12:34.5 帧]`（画面）、`[L03]` `[R01]`（回看核对）。你看不到视频，只能用这些笔记。

## 要做的

1. **按子问题合并**：把问题拆成用户真正要弄清的几个子问题（按这批视频实际讲到的拆，不要凭空列），每个子问题下把各期讲到的合在一起写。
   - 几期说法一致的，合成一句，来源都标上。
   - 几期说法不同的（参数不同、做法相反、条件不同），分开写清谁说了什么、在什么条件下，不要替他们裁决，也不要取平均。
   - 只有一期讲到的，照写，标明只有这一期。
   - 子问题按信息量排：讲得最具体、最能直接用的放前面。
2. **每期的增量**：每期一句话，写它有、而别的期没有的东西；没有增量的写“没有别处没讲的”。
3. **先看哪几期**：如果用户只看两三期原片，看哪几期，各一句理由（理由写这期里有什么，不写赞美）。分量是 none 的期不要选。
4. **总回答**：三五句话，先回答问题，再说最要紧的分歧或条件。

## 规则

- 只用笔记里有的内容，不加自己的知识、常识和评论；笔记里没有答案的子问题，写“这批视频都没讲”。
- 来源原样带过来，前面加期号：`[V3 12:34 说]`、`[V3 12:34.5 帧]`、`[V3 L03]`。一句话来自几期，几个来源都标。只能指到一期而指不到时刻的，写 `[V3]`。
- 笔记里标了“未核实”“画面看不清”“两个模型说法不同”的，带过来时保留这几个字，不要当成确定的事实合并。
- 保持原话的程度、条件和归属：讲者的经验、推测、个人偏好不要写成定论；“一般”“我习惯”“这台机器上”这类限定要保留。
- 原文没有的数量词、频率词、限定词（“一次”“每次”“都”“只”“大约”）不要加。
- 用克制、准确、信息密集的中文写。保留原文的中英专名、型号、参数写法。

## 输出

只输出一个 JSON 对象：

```json
{"answer": "总回答（Markdown，带来源）", "first": [{"v": 3, "why": "一句理由"}], "sections": [{"title": "子问题", "body": "合并后的内容（Markdown，带来源）"}], "videos": [{"v": 3, "adds": "这期的增量"}]}
```

- first 最多 3 期。videos 每期一项，按增量从多到少排。
