# 综合：把一批视频的笔记合成对一个问题的回答

用户一次看了一批视频，想弄清一个问题：{question}
{notes}
今天是 {today}。

下面是每期视频的笔记，按 V1、V2……编号，每期写了频道、发布日期、分量和要点；笔记记下了利益相关和转述的，也写在头上。每期的笔记都是另一个写作代理照着底稿和回看写的，事实后面标了来源：`[12:34 说]`（讲者原话）、`[12:34.5 帧]`（画面）、`[L03]` `[R01]`（回看核对）。你看不到视频，只能用这些笔记。

{comments}

## 回答由论断组成

把各期讲的拆成一条条论断：每条一句话、标来源、写出自哪几期（`v`），分四类，各按各的规矩：

- **事实**：可以核对的数据、发生过的事。两期数字不同，先对口径（指标、统计范围）和时点（哪个月的数、哪天的价）：对齐后不矛盾就不是分歧，留较新的，旧的写 `status: 被取代`、`by` 写取代它的论断 id。新的数据取代旧的数据。
- **解读**：对原因、意义、影响的看法。几期看法相反，各自成一条论断，在 `disputes` 里列成一条分歧：争的是什么、各方是哪几条论断、什么证据能判定、你的倾向和理由（判断不了写「不下倾向」）。不要揉成一句，也不要悄悄只取一边。
- **预测**：对将来的判断。写 `due`（到期日 YYYY-MM-DD：按那期的发布日期换算「明年」「年底前」这类说法，笔记里换算过的照抄）和 `condition`（怎么算应验）；时间说不清的写 `vague: true`，确定性下调一级。两期预测相反：都列，分歧里写各自的依据和能判定的事件，不提前判对错。后来的期里有事实结算了它：`status` 写 `应验` 或 `落空`、`by` 写那条事实；结算了的预测不再和别的说法并列成观点。
- **建议**：该怎么做。`premise` 写它成立的前提。

同一个频道前后说法不同，是改口不是分歧：旧的写 `status: 被取代`、`shift: true`、`by` 写新的；新的那条写上它给的理由。

## 来源和确定性

- **只数独立来源**：几期转述同一份报告、同一个人的观点，只算一个来源（`independent` 写独立来源数），`sources` 里写清各期转述的是什么。确定性不因为转述的期数多而上调。
- **利益相关**：头上写了赞助、广告、卖课、持仓的，`sources` 的 `interests` 写明；它撑着的论断确定性下调一级。
- **确定性**分四级，每条论断写一级，不是「高」的在 `why` 里写一句为什么：
  - 高：两个以上独立来源一致，有数据或原始材料（画面上的表格、文件）撑着。
  - 中：一个可靠来源，或几个来源大体一致但有出入。
  - 低：只有一个来源的看法、来源有利益相关、或说法含糊。
  - 很低：来源互相矛盾又判断不了，或只有转述的转述。
- 只有一个独立来源的论断最多「中」；是解读或预测的最多「低」，不进总回答，除非总回答里写明「只有 V4 讲到」。
- **来源一边倒**（各期立场都一样）：总的确定性下调一级，`balance` 写缺哪一方的来源。

## 要做的

1. **论断**（claims）：按上面的规矩拆，id 用 C1、C2……。
2. **按子问题分节**（sections）：把问题拆成用户真正要弄清的几个子问题（按这批视频实际讲到的拆，不要凭空列），每节列它的现行论断 id，讲得最具体、最能直接用的在前。这批视频都没讲的子问题，`note` 写「这批视频都没讲」。
3. **分歧**（disputes）；**来源**（sources）：每期一项，`stance` 用一两个词写这期在问题上的立场。
4. **总回答**（answer）：三五句话，先回答问题，再说最要紧的分歧或条件；`certainty` 写总的确定性和一句为什么。
5. **先看哪几期**（first）：如果用户只看两三期原片，看哪几期，各一句理由（写这期里有什么，不写赞美）。分量是 none 的期不要选。
6. **每期的增量**（videos）：每期一句话，写它有、而别的期没有的东西；没有增量的写「没有别处没讲的」。
7. **这一版变了什么**（changes）：有上一版时最多 5 条：结论、确定性、新开的子问题、被取代或结算的说法；`answer_changed` 只在结论的意思变了时写 true，换了措辞不算。没有上一版时 changes 写空列表。

## 规则

- 只用笔记里有的内容，不加自己的知识、常识和评论。
- 来源原样带过来，前面加期号：`[V3 12:34 说]`、`[V3 12:34.5 帧]`、`[V3 L03]`；连着的几个也每个都加：`[V3 12:34 说][V3 13:02 帧]`。一句话来自几期，几个来源都标。只能指到一期而指不到时刻的，写 `[V3]`。
- 笔记里标了「未核实」「画面看不清」「两个模型说法不同」「时间含糊」的，带过来时保留这几个字，不要当成确定的事实合并。
- 保持原话的程度、条件和归属：讲者的经验、推测、个人偏好不要写成定论；「一般」「我习惯」「这台机器上」这类限定要保留。
- 原文没有的数量词、频率词、限定词（「一次」「每次」「都」「只」「大约」）不要加。
- 有上一版时：同一个说法沿用上一版的 id，新的接着编号；用户的标记照办，不要改回来。
- 用克制、准确、信息密集的中文写。保留原文的中英专名、型号、参数写法。

## 输出

只输出一个 JSON 对象：

```json
{"answer": "总回答（Markdown，带来源）", "certainty": {"level": "高 | 中 | 低 | 很低", "why": "一句话"},
 "claims": [{"id": "C1", "type": "事实 | 解读 | 预测 | 建议", "text": "一句论断（带来源）", "v": [3, 5], "independent": 1,
             "certainty": "高 | 中 | 低 | 很低", "why": "不是高时写", "status": "现行 | 被取代 | 落空 | 应验", "by": "C7",
             "shift": false, "due": "2026-06-30", "condition": "怎么算应验", "vague": false, "premise": "建议的前提"}],
 "sections": [{"title": "子问题", "claims": ["C1", "C2"]}],
 "disputes": [{"id": "D1", "about": "争的是什么", "claims": ["C3", "C8"], "decide": "什么证据能判定", "lean": "倾向和理由"}],
 "sources": [{"v": 3, "stance": "立场", "relays": "转述的什么", "interests": "利益相关"}], "balance": "",
 "first": [{"v": 3, "why": "一句理由"}], "videos": [{"v": 3, "adds": "这期的增量"}],
 "changes": ["这一版变了什么"], "answer_changed": true,
 "replies": [{"id": "N1", "result": "已改 | 没改 | 已答 | 记进待修", "text": "怎么处理的"}]}
```

- 用不到的字段不写：`due`、`condition`、`vague` 只给预测，`premise` 只给建议，`shift` 只给改口，`note` 只给都没讲的子问题。`replies` 只在有给你的批注时写。
- first 最多 3 期；videos 每期一项，按增量从多到少排。
