# 写作：按写作提示词，用底稿和回看结果写这期的笔记

用户在一次看一批视频，想弄清一个问题：{question}
{notes}
{day}

材料（都在下面）：

- 写作提示词：先读这份，照它写。
- 回看结果：每条有 question、answer、evidence、sure，以及 start/end（原片秒数）。
  - sure 是模型自评：false 的当作“未核实”；true 也不等于可信。
  - 屏幕、幻灯片、板书上的字和数字，回看读到就能用。实物上印的小字（罐身、包装、铭牌）和画面状态（弹的是哪个框、点没点下），要两个模型一致才能用。
  - 左右、手、脚、姿势、位置这类判断，要有 answer2（第二个模型独立看同样画面的回答）且两个一致才能用；只有一个回答的（包括 clip 的回答）写“未核实”。两个不一致，写“画面看不清，两个模型说法不同”，两个回答都列出来。
- 底稿。

底稿怎么读：

- `说：` 是 Whisper 转写，讲了什么以它为准。中文里夹的英文代码、人名可能转错。
- 画面记录（`[mm:ss-mm:ss] 类型…` 和下面的字段）的时间、场景可信，里面的数字、小字、左右不能单独当依据。
- `高清帧 mm:ss.s：` 是原片单帧逐字照抄，屏幕文字可信；图例、坐标轴这类小字里 5/6、3/8、x/% 可能混。

写法：

- 来源写成 `[12:34 说]`（转写）、`[12:34.5 帧]`（高清帧）、`[L03]`（回看）。时间照抄底稿里的写法。
- 来源标在事实真正出现的那一刻。卡片、幻灯片、表格上的内容，标那张画面的时间。
- 原文没有的数量词、频率词、限定词（“一次”“每次”“都”“只”“大约”）不要加。
- 图上没印出来的价位不要估算，写“图上没标出”。
- 判断“讲者说的和画面对不对得上”时，拿讲者说这句话那一刻（前后 2 秒内）的画面比。
- 操作步骤的先后，按回看和高清帧里的时间排。
- 没有直接看到的不推断：“第一条”“最后一步”“第几行”“共几项”只在画面完整露出时写；只露出一部分的，写“画面露出的第一行是……”。来源标在内容完整出现的那一帧。
- 转写同音字按意思改之前，先对屏幕上的字（字幕、板书、图表、界面、包装）；没对上的，保留转写原文并标“未核实”。
- 时间词（「明年」「下个季度」「年底前」「下周」）按这期的发布日期换算，写在原话后面的括号里：「明年上半年（2026 年上半年）」；说不清是哪段时间的标「时间含糊」。
- 讲者的预测写清到什么时候、怎么算应验：讲者说了的为准，没说就写「没说怎么算」。
- 讲者转述别人的报告、研究、观点时，写清转述的是谁、哪份、什么时候的（讲者说了才写），标来源。
- 视频里的广告、赞助、卖课、推荐自己的产品或服务，讲者说自己持有、做空、重仓某个标的：在笔记最后单列一节「利益相关」，每条标来源；没有就不写这一节。
- 只写视频里有的内容，不加自己的知识和评论。

## 要交的

1. 这期的笔记（Markdown），从第一行就开始写笔记，不要写开场白。不要写视频标题当一级标题，页面上已经有。
2. 补看清单：把笔记里标了“未核实”、而回到原片看画面有可能定下来的地方列出来。讲者没说、画面上本来就没有的，不要列。能回原片定下来的都列，最多 25 条；同一屏、同一段能一起问的合并成一条。id 用 R01、R02……，格式：

```json
{"id": "R01", "start": "01:43.5", "end": "01:46", "mode": "frame | frames | zoom | clip", "step": 1, "times": ["只在读分散时刻时写"], "second": false, "target": "zoom 时必填", "question": "只问一件具体的事", "why": "笔记里哪一处未核实，现有来源是什么情况"}
```

   - start、end 照抄底稿里的时间格式（`mm:ss`、`mm:ss.s`），不要换算成秒。画面记录的时间早约 2 秒，前后各留 2–3 秒。
   - frame：静止的整屏。frames：会变的字和数字，每隔 step 秒（最小 0.2）一张全分辨率帧，最多 8 张；停留不到 1 秒的画面用 0.2–0.3 秒。frames 写 `times`（最多 8 个时刻，不用写 start、end）：一次读几处分散的字，转写同音字能在屏幕上找到对应字的都合并到这里。实物小字用 zoom、画面状态用 frames，都加 `"second": true`。zoom：小区域，target 写清颜色、位置、长相。clip：只看次数、先后、往哪个方向动，低清，不能读字。左右、位置和手、脚、姿势细节：frames 或 zoom 加 `"second": true`。
   - 取帧范围不要跨转场。
   - 同一处已经回看过、回答是“看不清”或“画面上没有”的，换一种 mode 或换时间再列；换不出办法的不列。
   - 手指、手掌这类细节两个模型已经说法不同的，不再列：画面多半就不够，写“画面看不清”。
   - 价格只问图上印出来的数字，不要让它按坐标估算。
3. 这期对问题的分量：`high`（正面讲了问题的一部分）、`some`（只沾边）、`none`（无关）；和一句话的要点（这期对问题有什么，不超过 40 个字）。
4. 利益相关和转述：和笔记里写的一致，各一条一句、带来源（没有就是空列表）。

## 输出格式

先输出笔记全文。笔记之后，单独一个 ```json 代码块收尾，里面是：

```json
{"fit": "high | some | none", "gist": "一句话要点", "interests": ["持仓：重仓 XX [12:00 说]"], "relays": ["转述某投行 10 月的报告 [03:10 说]"], "looks": [补看清单，没有就是空列表]}
```

代码块后面不要再写任何东西。
