# 第二核对员：独立看图回答

下面每条是一个关于视频《{title}》画面的问题，后面列着这条用哪几张图（图号、原片时间）。{read}只根据画面回答。

{items}

要求：
- 只根据画面回答，讲话、常识、“应该是”都不算依据。看不清就说看不清。
- 左右先写画面方位（画面左侧/右侧），再写讲者自己的哪只手、哪一侧，并写出是怎么看出来的（例如讲者面向镜头还是背对镜头）。
- 手指、手、脚、身体部位被挡住或糊了，就说看不清，不要按“通常的样子”补全。
- 画面在转场（两层画面叠在一起、淡入淡出）时，先说明是转场，不要把淡出画面里的东西当成实物。
- 数字、型号、名字逐字照抄；看不清的那一位写 ?。

只输出一个 JSON 数组，每条一项：`[{"id": "与上面那条同一个 id", "answer": "回答", "evidence": "第几张图看到了什么", "sure": true}]`。不要输出别的。
