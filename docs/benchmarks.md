# 基准：补丁与它们依赖的外部限制

流水线里有相当一部分复杂度，不是视频本身要求的，而是给模型和工具的限制打的补丁。这些限制会随模型和工具升级而变化。每周跑一次基准，重新实测这些限制；一旦某条限制消失，对应的补丁就可以删掉，流程随之简化。删不删由人决定，基准只给出数据和建议。

## 怎么跑

在 prodbox 的 worker 容器里运行（默认用设置 `llm_provider` 的 provider 跑全部工序，不反映 `stage_providers`；`--provider` 可以临时指定 agy 或 tuzi）：

```bash
lzc-cli docker -- exec -w /lzcapp/pkg/content cloudlazycatappassetizer-worker-1 python -m assetizer.cli bench
```

- `--only probes`：只跑便宜的探测，不需要基准视频，约 ¥0.5。
- `--only quality`：只跑基准集上的质量对比，每期 58 分钟的视频约 ¥2。
- 报告写在 `<home>/bench/reports/<YYYY-MM-DD_HHMM>.md` 和同名的 `.json`，会自动和上一份报告对比。
- 每次跑都用新的目录，不复用上次的模型回答；基准视频和代理文件缓存在 `<home>/bench/media/`。

## 基准集

标注文件在 `src/assetizer/bench/golden/<视频 id>.json`，随代码一起打包。每个文件记录视频的地址、时长和文件哈希，以及：

- `units`：知识单元，包括标题、标的、起止秒数、优先级；
- `boundaries`：片段边界，包括单元、起止秒数；
- `provenance`：这些答案从哪里来、可信度如何。要区分**标准答案**（逐条核对过）和**参照答案**（整体验收过，但没有逐条核对）。拿参照答案测出来的只是"整段和分段的差距"，不是绝对准确率。

| 视频 | 类型 | 时长 | 知识单元 | 片段边界 |
|---|---|---|---|---|
| 1MuKAUgL4r4 交易员汤姆 09/08 技术分析 | 交易图表复盘 | 58 分钟 | 30 个，参照答案（Run-014 整体验收） | 24 个，标准答案（局部 ASR + 每端 5 帧核验） |

目标扩展到"所有值得留档学习的视频"之后，基准集要覆盖不同类型：讲座和课程、访谈和播客、带屏幕演示的教程、板书类视频。新增一期时：

1. 先用流水线跑出一版，再逐条核对知识单元（漏了什么、多了什么、起止时间对不对），修正后写进标注文件；
2. 在 `provenance` 里写清楚哪些部分核对过；
3. 基准集一旦确定就不再随意改动，否则不同周的结果无法横向比较。要改的话，在报告里注明。
